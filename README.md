# monitor-operativo

Monitoreo externo y reportes de los servicios operativos de Andres, sin depender de ninguna laptop ni de una sesión abierta (política general del 11/10/2026).

Este repositorio es **público**: no contiene secretos, direcciones ni nombres de clientes. Las direcciones sondeadas viven en una variable del repositorio (no visible al público) y todo lo que se publica usa solo alias.

Estado: en construcción (fase 1 del plan de monitoreo).
